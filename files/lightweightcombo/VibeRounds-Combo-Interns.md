# VibeRounds — Intern Combo

## Who this is for
PGY-1 / interns still building illness scripts, ward routine, and basic safety habits. The goal at this stage is **volume of safe reps**, not depth — catch anchoring early, build pattern recognition, and keep confidence intact while doing so.

## Why these modules
Everything below is either a daily-workflow module (rounds, med rec) or a safety-net module (time-out, anchor extractor) that pays off immediately at the bedside, plus one framework that keeps the tone supportive rather than punishing.

## The Combo (9 modules)

| Order | Module | Why it's here |
|---|---|---|
| 1 | [Module 0 — Cold-Start Orientation](https://avi33tbtt.github.io/Prompts/Module-00-Cold-Start-Orientation.html) | One-time entry point — routes you correctly before anything else |
| 2 | [Module 1 — Socratic Clinical Reasoning](https://avi33tbtt.github.io/Prompts/Module-01-Socratic-Clinical-Reasoning.html) | Default mode for every case discussion — forces active reasoning instead of spoon-fed answers |
| 3 | [Module 4 — Peer-Level Ward Round Preparation](https://avi33tbtt.github.io/Prompts/Module-04-Peer-Level-Ward-Round-Preparation.html) | Your daily bread and butter — rounds, admissions, overnight triage |
| 4 | [Module 15 — Illness Script Acquisition](https://avi33tbtt.github.io/Prompts/Module-15-Illness-Script-Acquisition.html) | Builds the pattern library you don't have yet |
| 5 | [Module 13 — Medication Reconciliation & Polypharmacy Audit](https://avi33tbtt.github.io/Prompts/Module-13-Medication-Reconciliation-Polypharmacy-Audit.html) | Highest safety-yield-per-minute task an intern does |
| 6 | [Module 28 — Diagnostic Time-Out](https://avi33tbtt.github.io/Prompts/Module-28-Diagnostic-Time-Out.html) | A forced pause before committing to a plan |
| 7 | [Module 30 — The "Diagnostic Anchor" Extractor](https://avi33tbtt.github.io/Prompts/Module-30-Diagnostic-Anchor-Extractor.html) | Catches premature closure — the #1 intern cognitive error |
| 8 | [Module 52 — Clinical Pearls Distillation](https://avi33tbtt.github.io/Prompts/Module-52-CP-Clinical-Pearls.html) | Turns each case into something that sticks |
| 9 | [Framework A — Humanistic Persona & Confidence-Building Trait Set](https://avi33tbtt.github.io/Prompts/Framework-A-Humanistic-Persona.html) | Keeps the AI's tone confidence-building, not intimidating, at the stage it matters most |

## Suggested workflow
Run **Module 0 once**. Then for each new case: **1 → 4/15 (whichever fits the moment) → 13 (if a med list exists) → 28 → 30 → 52** at sign-out. Layer **Framework A** into all of the above — it's not run standalone.
