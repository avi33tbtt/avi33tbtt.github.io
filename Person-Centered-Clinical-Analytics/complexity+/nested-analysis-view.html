Nested Analysis View — Unified Cohort Trajectory Map

cohort_graph.json → one alluvial network of every patient's checkpoint sequence, every condition in the file overlaid on shared nodes · runs entirely in-browser, no Python/Node required
What this is. This page nests every patient's trajectory in whatever cohort_graph.json you load into a single network — every patient walks the same six generic checkpoints (Diagnosis → Presentation → Initial plan → Escalation → Advanced/recurrent → Disposition), and where two or more patients land on the same checkpoint value, their lines are drawn through one shared node instead of parallel ones. The map and filters below now cover every condition present in the file (not just two), plus escalation-frequency, comorbidity, age, gender and free-text patient search. Pick a patient below to see their own path highlighted against the rest of the cohort. Synthetic data only, not clinical decision support.

What the convergence pattern shows

Confounder. This nested view reuses the same six generic checkpoint slots for every patient regardless of disease — but different conditions log outcome events at very different rates (e.g. acute-spike conditions like T1D recur every checkpoint, while others may only have one or two outcome events on file), so the Escalation / Advanced-recurrent columns read "—" much more often for lower-event-density conditions. That's a real difference in this synthetic corpus's event density per disease, not a rendering gap. Use the "Escalation / outcome events" filter above to isolate patients with denser event histories for a fairer cross-condition read.
