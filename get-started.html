⚡Quick 2-Minute Setup to Connect an LLM

Getting Vibe Rounds up and running takes about two minutes: grab a free API key, paste it into the Setup panel, and you're ready to start a clinical round. The two steps below walk you through it.

1Get an API Key

Vibe Rounds works with Claude, Gemini, ChatGPT, or any OpenAI-compatible provider (Groq, OpenRouter, DeepSeek, and more). If you don't already have a key, the easiest free option is OpenRouter:

  • Visit openrouter.ai and create a free account.
  • Open your account dashboard and generate a new API key. Keep it private — treat it like a password.

Already have a Claude, Gemini, or OpenAI key? You can use that directly instead — skip ahead to Step 2.

2Configure the Suite

Open the Vibe Rounds Clinical Learning Suite and go to the Setup and API Key section. Choose your provider tab and enter your details:

Using a native provider (Claude / Gemini / ChatGPT)

Click the matching tab, paste your API key, and confirm the model name — each tab shows a sensible default.

Using OpenRouter or another OpenAI-compatible provider Free Version Recommended

This is the recommended path — one free OpenRouter key gives you access to Claude, Gemini, GPT, and dozens of other models without juggling separate accounts.

Click the Other tab and enter:

ParameterValue
API Endpointhttps://openrouter.ai/api/v1/chat/completions
Model Namegoogle/gemini-2.5-flash (or any model listed on OpenRouter)
API KeyYour OpenRouter key

Your key is saved only in your browser's local storage and is sent directly from your browser to the provider — never through any server of ours.
