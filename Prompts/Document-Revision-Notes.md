# Document Revision Notes (Internal — Not Published)

Holding place for decisions about the Prompt Modules document that are no longer
surfaced in the published document itself, plus the version history that used
to live inside it.

## 1. Persona Naming — Licensed Terms Removed

All persona language across the project uses non-licensed educational roles only
(see Framework A's Persona Language Register). Licensed-sounding labels —
"MBBS intern," "qualified doctor," "attending," "consultant," "Socratic Attending,"
"Supportive Intern," "Junior Resident," or anything else implying clinical
licensure or authority — are retired.

This is a project-wide rule, not a document-only one: website persona cards,
demo videos, and onboarding copy should match the same non-licensed labels used
in this document (e.g. "educational assistant using the Socratic method,"
"peer-level thinking partner," "documentation companion").

## 3. "What / Where / Do" — Not a Standalone Framework

Unlike Frameworks A–D, "What / Where / Do" does not get its own specification
file. Its three components are already distributed across the same three-phase
lifecycle every module runs on:

- **What** → Initiation: identify the case, the role, the goal
- **Where** → Execution: localize the clinical question, run the targeted
  reasoning, query, or audit
- **Do** → Closure: produce the action, plan, note, or handover

It's the same lifecycle pattern restated for the bedside-facing product framing
— no separate document needed.
