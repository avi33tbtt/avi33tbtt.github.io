Admission & Presentation

From first encounter to working diagnosis. These tasks run during assessment, triage, and the first diagnostic cycle. The AI interrogates your reasoning — it does not hand you a diagnosis.

First contact & orientation
Route-finding for a new session
M00
If you are new or unsure which module fits your situation, M00 identifies your role and routes you before any clinical data is entered.
I am a [student / registrar / consultant / advocate]. My current clinical question is [question]. Run Cold-Start Orientation to identify the right module.
Compress the case to a problem representation
M17
Before building a differential, compress the case to a one-sentence semantic problem representation. Qualifiers: acuity, severity, time course, host factors.
Run M17 on this case. Case: [paste history and exam findings]. Help me compress this to a precise one-sentence problem representation using semantic qualifiers.
Build the illness script for the leading candidate
M15
Build the formal illness script for the suspected disease and use it as the comparator against your patient's actual findings.
Run M15 on [suspected diagnosis]. Then compare the illness script against this patient: [key findings]. Where does the patient fit the prototype and where do they deviate?
Differential diagnosis deep dive
M12
Expand, re-rank, and interrogate the differential. For each entry: what supports it, what excludes it, what investigation would move it up or down.
Run M12 on this case. Working diagnosis: [diagnosis]. Current DDx: [list]. Case summary: [findings]. Expand, re-rank, and interrogate each item.
Diagnostic reasoning
Test each hypothesis deductively
M56
State the leading hypothesis. The AI generates its testable predictions, then checks each against the case data — surfacing where evidence supports, undermines, or is absent.
Run M56 (Hypothetico-Deductive Model). Leading hypothesis: [diagnosis]. Case: [summary]. Generate the predictions this hypothesis makes, then test each against the data.
Apply Bayesian likelihood ratios to key findings
M36
For each key finding, estimate pre-test probability and apply likelihood ratios. The AI audits numeric reasoning and shows how each finding shifts the posterior probability.
Run M36 (Bayesian Engine) on this case. Key findings: [list]. Leading diagnoses: [list]. Audit my probability estimates and show how each finding shifts the posterior.
Separate causal from probabilistic reasoning
M18
Run the case through both lenses. The AI surfaces where you are reasoning causally when the data only supports probabilistic inference — and vice versa.
Run M18 on this case. Case: [summary]. Working diagnosis: [diagnosis]. Identify where my reasoning is causal and where it is only probabilistic.
Map first-principles pathophysiology
M31
Build the mechanistic chain from underlying biology to clinical presentation. The AI challenges every assumed step and asks for the molecular mechanism.
Run M31 on this presentation. Case: [findings]. Build the first-principles pathophysiological chain from mechanism to the clinical picture in front of me.
Red herring / signal-to-noise drill
M37
Classify every finding as signal, noise, or red herring. The AI challenges every classification. Use when a case feels complex because of data volume, not genuine ambiguity.
Run M37 on this case. All findings: [full data set]. Classify each finding as signal, noise, or red herring — then interrogate my classifications.
Audit your pattern recognition
M20
Name the pattern you fired first. M20 runs the Recognition-Primed Decision model — what cues triggered it, what mental simulation you ran, where System 1 may have short-circuited.
Run M20 (Naturalistic Decision Making). The pattern I fired on this case: [pattern/diagnosis]. Case: [summary]. Audit the cues, the mental simulation, and the risk of premature closure.
Extract and interrogate the diagnostic anchor
M30M26
Identify the single finding most powerfully anchoring the current diagnosis. Defend it, test its reversibility, and reason through what happens if the anchor is wrong.
Run M30 → M26 on this case. Case: [summary]. Working diagnosis: [diagnosis]. Extract the diagnostic anchor, then run a full bias audit on my reasoning.

Ward Round

Structured preparation, real-time case review, and on-round decision auditing. The AI plays a senior peer — probing each element and insisting on justification before you move on.

Preparation
Ward round preparation — structured SBAR
M04
Prepare the structured SBAR presentation for each patient. The AI acts as a senior peer, probing the problem list, active issues, outstanding investigations, and planned interventions.
Run M04 (Ward Round Preparation). Patient: [age, sex, day of admission]. Diagnosis: [working diagnosis]. Summary: [24hr events, vitals, key data]. Outstanding issues: [list]. Drill my presentation.
Overnight trend analysis
M27
Plot the trajectory of key parameters overnight. The AI identifies acceleration, deceleration, plateau, and trend reversal — then asks for clinical interpretation of each velocity change.
Run M27 (Time-Series Analyzer) on this patient's overnight data. Data: [vitals, obs, bloods with timestamps]. Identify velocity changes and ask me to interpret each one.
Real-time case review & data audit
M05
Query and clean the case log before the round. The AI identifies data gaps, inconsistencies, and entries requiring verification — asking you to explain each anomaly.
Run M05 (Real-Time Case Review) on this patient's record. Case log: [paste de-identified record]. Identify gaps, inconsistencies, and data points needing verification before the round.

Run M13 (Medication Reconciliation) on this drug chart. Patient: [age, weight, CrCl/eGFR, hepatic function]. Medications: [list with doses and frequency]. Diagnoses: [list].

On-round decisions
Diagnostic time-out before committing
M28
Pause at the moment of decision. What are we missing? What is the most dangerous diagnosis not yet excluded? Have we anchored prematurely? Assign explicit confidence levels before proceeding.
Run M28 (Diagnostic Time-Out) before I commit to this plan. Current diagnosis: [diagnosis]. Proposed plan: [summary]. Case: [key findings]. Force a full time-out.
Safety gate
High-value care audit of outstanding requests
M34
Audit every outstanding test, investigation, and referral. What is the pre-test probability? What will this change? Does the benefit justify the cost and patient burden?
Run M34 (HVC Auditor) on these outstanding requests. Requests: [list of tests/referrals]. Working diagnosis: [diagnosis]. Audit each for pre-test probability, clinical impact, and value.
"Why now?" — precipitant for acute change
M33
Why did this patient change overnight? The AI will not accept "the disease progressed" — it interrogates for a specific precipitant: physiological, pharmacological, behavioural, or social.
Run M33 ("Why Now?" Hunter). Patient with known [chronic diagnosis] has acutely [changed/deteriorated]. Clinical findings: [overnight data]. Find the precipitant.
Discharge planning & throughput strategy
M40
Identify bottlenecks, sequence dependencies, and timing risks in the discharge or ongoing management plan. Build a throughput sequence that maximizes safety without sacrificing efficiency.
Run M40 (Operational Strategist) for this patient. Remaining clinical tasks before discharge: [list]. Constraints: [bed pressures, specialty availability, investigations pending]. Sequence optimally.
Map certainty across the management plan
M35
For each claim in the plan, assign epistemic status: established fact, evidence-based inference, reasonable assumption, or speculation. Identify where the plan rests on conjecture.
Run M35 (Epistemic Certainty Mapping) on this management plan. Diagnosis: [diagnosis]. Plan: [list each element]. Map the certainty status of each claim.

Active Management

Ongoing treatment decisions, evidence integration, and management plan auditing. The AI stress-tests your plan across the Conservative → Maximal decision spectrum.

Treatment decisions
Compare treatment options with prognosis trajectories
M48
Compare two or more treatment options: mechanism, evidence quality, response timeline, adverse event profile, and prognostic trajectory. The AI then audits your reasoning for choosing one path.
Run M48 on this management decision. Options: [Option A vs Option B]. Diagnosis: [diagnosis]. Patient profile: [age, comorbidities, relevant factors]. Compare and then audit my reasoning.
Map the full decision spectrum
Decision Spectrum
For any management decision, map Conservative → Minimal → Balanced → Aggressive → Maximal with explicit rationale and uncertainty flags at each step. Defend your position on the spectrum.
Run the Decision Spectrum on this management question: [specific decision]. Patient: [summary]. Map all five positions with rationale, then ask me to defend where I am placing myself.
Check guideline concordance
M53
Map relevant clinical guidelines, identify where the management plan is concordant and where it deviates, and provide explicit justification for each deviation.
Run M53 (Clinical Guideline Navigator) on my management plan. Diagnosis: [diagnosis]. Plan: [list]. Identify which elements are guideline-concordant and interrogate each deviation.

Deteriorating Patient

Acute-on-chronic decompensation, multi-organ complexity, and cascading failure. These modules help you find the precipitant, model the cascade, and avoid missing the reversible cause.

Acute deterioration workup High acuity

M33
The AI will not accept "the disease progressed." It interrogates for a specific precipitant — physiological, pharmacological, behavioural, social — and audits whether you have actually looked for it.
Run M33 ("Why Now?") urgently. Patient: known [chronic diagnosis], now acutely [description of deterioration]. Findings: [vitals, bloods, clinical signs]. Find the specific precipitant.
Acute

Run M35 + M28 as a pre-handover check. Patient: [summary]. Current plan: [list]. Map what we are certain and uncertain about, and identify what the covering team must watch for.
