Not a decision-making tool. This runs the Module SDM — Shared Decision-Making Query Generator from the Vibe Rounds prompt library: load a case once, then fire each of the 7 query domains (or all of them) to generate patient-voiced, first-person questions — followed by a Phase 3 synthesis: a consolidated question set, an "Ask 3" priority distillation, a case-data gap check, and a reflection debrief. It never recommends a treatment or ranks options for the patient — its only output is the questions a patient or advocate should be asking.
Educational use only. To be used on personal responsibility and only for learning and preparation — not for clinical decision-making. Your API key is stored only in this browser's local storage and sent directly from your browser to your chosen provider — never through any server of ours.
