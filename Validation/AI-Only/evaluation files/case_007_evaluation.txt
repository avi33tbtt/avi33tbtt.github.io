======================================================================
1. FABRICATION / SOURCE-FIDELITY CHECK
======================================================================
PASS — and this is the most demanding test of the fabrication rule so far,
because for the first time most of Node 4 IS extractable text.

- Unlike Cases 005/006 (almost all investigations image-only), this case
  has substantial plain-text investigation data (ABG, 2D echo, USG, RFT,
  viral screen, RTPCR, staging label), and the map uses all of it with
  specific numeric values reproduced accurately and without embellishment
  (pH 7.24, urea 145, creatinine 1.9, etc.).
- Critically, it still correctly withholds the subset that IS image-only:
  HRCT thorax findings, biopsy histology/cytology description, and
  sputum AFB/CBNAAT results are explicitly marked "cannot be fully
  classified," even though the map could have been tempted to infer them
  from the T3N3M0 staging label or the stated final diagnosis. It
  explicitly declines to do this ("not inferred from the T3N3M0 staging
  label"), which is exactly the right discipline and shows the rule is
  being applied selectively/correctly rather than as a blanket "all of
  Node 4 is off-limits" shortcut.
- The CONTAMINATION FLAG now states the boundary in the clearest form
  yet across all four cases evaluated: "Most numeric investigation
  results... were available as plain text and used directly... However,
  [list] are presented only as embedded images." This directly satisfies
  the recommendation made in Cases 004–006's evaluations to state the
  text-vs-image boundary explicitly, and does so more precisely because
  it names which specific items fall on which side rather than a general
  statement.

2. STRUCTURAL COMPLETENESS
======================================================================
STRONG, and appropriately scaled up. This is a denser, three-process case

3. REASONING QUALITY
======================================================================
- Node 1: cleanly separates the month-long respiratory/constitutional
  syndrome from the 4-day GI illness as two branches from the outset —
  consistent with the pattern in Cases 005/006 of not collapsing distinct
  problems into one differential prematurely.
- Node 2: the "anaemia" label given during the initial month-long episode
  is correctly identified as a likely early anchor that delayed
  recognition of a structural pulmonary process — a sharp catch, and one
  the map is careful to note was "appropriately revised" later rather
  than overstating the error.
- Node 3: this is the richest node across all four cases evaluated.
  Two findings stand out for genuinely good reasoning:
    (a) 3c, the left supraclavicular (Virchow's) node — correctly
        identified as a classic sentinel malignancy finding and
        correctly linked forward to the biopsy that the case actually
        pursued (i.e., the map's read of "this should prompt tissue
        diagnosis" matches what the source case did, not just what it
        should have done — verifiable coherence).
    (b) 3f, the examiner's own "?Portal hypertension" query — the map
        correctly treats a clinician's own noted-but-unpursued question
        as a decision point in its own right, which is a more
        sophisticated move than the discordant-finding catches in prior
        cases (JVP/ascites in Case 005, GRBS in Case 006) because here
        the source material itself already flagged the tension; the
        map's contribution is holding the team accountable for their own
        unfinished thread, not just identifying an unflagged discordance.
  3e (saddle nose deformity) is also a nice catch — correctly identified
  as raising a distinct differential (vasculitis/relapsing polychondritis/
  chronic infection) that the map is honest is never reconciled with the
  malignancy-focused final diagnosis.
- Node 4: correctly reasons the RFT findings (elevated urea/creatinine/
  uric acid) toward two competing mechanisms (AKI from volume depletion
  vs. tumor-lysis-adjacent process) without picking one — appropriate
  restraint given the source doesn't resolve it. The "Unused results"
  note (RPD changes on USG never revisited against later creatinine rise)
  is a genuinely useful catch of a missed reconciliation, distinct from
  simply flagging missing data.
- Node 5: the closure-type analysis is the most differentiated of any
  case so far — it correctly identifies that different components of a
  compound diagnosis can have different closure types simultaneously
  (malignancy = analytical/System 2 via biopsy; cardiac and GI = more
  pattern-driven, run in parallel). This is more nuanced than Cases
  004–006, which each assigned a single closure-type judgment to the
  whole synthesis.
- HIGHEST-YIELD DECISION POINT: well-justified, and the stated lesson
  ("a self-generated clinical query deserves the same evidentiary
  follow-through as an externally raised one") is a genuinely
  transferable teaching point, arguably the most generalizable insight
  produced across the four cases evaluated.

4. WEAKNESSES / RISKS
======================================================================
- Node 3f's open branch (portal hypertension) and the saddle nose finding
  (3e) are both restated across Node 3, Node 5, and the bias audit
  (search satisficing), similar to the repetition noted in Case 006 for
  the epigastric-tenderness branch. Here it is arguably better justified
  because the map is tracking two distinct unresolved threads rather than
  one, but a cross-reference rather than three full restatements would
  tighten the document.
- The "Anchoring" bias entry (Node 2a, the "anaemia" label) and part of
  "Commission/Omission" and "Search satisficing" entries circle similar
  territory (things raised-but-not-pursued) without being clearly
  distinguished from each other by mechanism — a minor version of the
  anchoring/availability overlap flagged in Case 006.
- As in all prior cases, the numeric values reproduced from "extractable
  text" (ABG, RFT, echo findings) have not been independently verified by
  this evaluator against the live source URL; this evaluation assesses
  internal consistency and protocol adherence, not ground-truth accuracy
  of the transcription itself.
- One small internal tension: Node 1's insight states the presentation
  "should activate separate branches... since the eventual working
  diagnosis explicitly names both a pulmonary process and acute
  gastroenteritis as distinct entities" — this uses knowledge of the
  final diagnosis to justify how Node 1 should have been reasoned about,
  which is a mild (and probably unavoidable, since the DRM is written
  retrospectively) instance of the same hindsight/framing effect the map
  itself calls out in the Framing bias entry. Worth flagging as a
  structural feature of retrospective DRMs generally, not specific to
  this case.
